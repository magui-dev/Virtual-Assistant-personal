다운로드

Windows용 다운로드 macOS용 다운로드 (사용 불가)
⚠️ macOS는 Apple Developer 코드 서명이 필요하여 현재 지원하지 않습니다.

⚠️ 설치 안내

다운로드 시 브라우저 또는 Windows Defender가 경고를 표시할 수 있습니다.

1. 브라우저 다운로드 경고:

"파일 삭제" 또는 "위험한 파일" 경고 시
→ "계속 다운로드" 또는 "보관" 선택

2. Windows Defender 실행 차단:

"Windows의 PC 보호" 알림 시
→ "추가 정보" 클릭 → "실행" 선택

💡 이 경고는 디지털 서명이 없는 앱에서 일반적으로 나타나는 현상입니다.
실제 바이러스가 아니니 안심하고 사용하세요!

시스템 요구사항

Windows: Windows 10 이상 (64-bit)

macOS: ⚠️ Apple Developer 코드 서명 문제로 현재 지원 중단

메모리: 최소 4GB RAM

저장공간: 500MB 이상
